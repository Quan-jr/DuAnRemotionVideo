# 🎙️ HƯỚNG DẪN ĐƯA GIỌNG MẪU (VOICE CLONING) VÀO HỆ THỐNG

Thư mục này dùng để lưu trữ các file âm thanh giọng mẫu để AI tự động nhân bản (Voice Cloning).

### 📋 Cách sử dụng:
1. Chuẩn bị 1 đoạn ghi âm giọng nói rõ ràng (độ dài lý tưởng từ **3 đến 10 giây**).
2. Đặt tên file là `sample.wav` hoặc `sample.mp3` (hoặc `my_voice.wav`).
3. Chép file vào thư mục này: `D:\vidv2\voice_samples\sample.wav`.

---

### 🌟 Lưu ý để chất lượng giọng clone đạt chuẩn cao nhất:
* Âm thanh không lẫn tiếng ồn xe cộ, không có nhạc nền.
* Người nói phát âm rõ ràng, tốc độ vừa phải.
* Định dạng tối ưu: `.wav` 44.1kHz hoặc 48kHz (hoặc `.mp3` 192kbps+).
